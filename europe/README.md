# כדורגל באירופה ⚽

אפליקציית ווב (PWA) שבה בוחרים מדינה באירופה ותאריכים, ורואים את כל משחקי הכדורגל שמתקיימים בה:
ליגות מקומיות, ליגת האלופות, הליגה האירופית, הקונפרנס, ליגת האומות והגביעים.

## מה יש באפליקציה
- **בחירת תאריכים בלוח אחד** – לוחצים על יום היציאה ואז על יום החזרה, והטווח מוחל מיד. מתחת לכל יום יש פס שמראה כמה משחקים יש בו.
- **מפה** – כל המשחקים בתאריכים שבחרת על מפת אירופה. לחיצה על אצטדיון מציגה את המשחקים בו ואת כל המשחקים עד 350 ק״מ ממנו, גם במדינות שכנות.
- **מסך מדינות** – כל מדינה עם מספר המשחקים בטווח התאריכים שנבחר, הליגות והמשחק הבא. סינון לפי אזור וחיפוש.
- **דף מדינה** – משחקים לפי ימים, סינון לפי ליגה, עיר, קבוצה, סופ״ש בלבד או מועד סופי בלבד.
- **סופי שבוע** – כמה משחקים יש בכל סופ״ש. לחיצה על סופ״ש בוחרת אותו, ו־🔥 מסמן סופ״ש עמוס.
- **שעון מקומי ושעון ישראל** לכל משחק.
- **מועדפים** – שמירה על המכשיר, שיתוף בוואטסאפ והורדה ליומן (‎.ics). לכל משחק יש גם קישור ליומן Google ולמפה.
- **התקנה כאפליקציה** בטלפון (״הוסף למסך הבית״) והצגת הלוח גם בלי אינטרנט.
- **קישור לשיתוף** – כתובת הדף שומרת את המדינה, התאריכים והסינון.

## עדכון אוטומטי
`.github/workflows/europe-update.yml` (בשורש ה-repo) מריץ את `europe/scripts/update.py` פעמיים ביום. הסקריפט:
- ממלא תוצאות של משחקים שהסתיימו ומסמן משחקים חיים או נדחים;
- מעדכן תאריך ושעה כשמועד משתנה, וממלא שעה למשחקים שהשעה שלהם עוד לא נקבעה;
- שומר את `data/games.json` ומבצע commit רק כשיש שינוי.

אפשר להריץ אותו גם ידנית: Actions ← europe-update-games ← Run workflow.

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html`, `style.css`, `app.js` | האפליקציה |
| `data/games.json` | לוח המשחקים (מדינות, ליגות, משחקים) |
| `scripts/update.py` | עדכון אוטומטי (סטטוס ההרצה האחרונה ב-`data/update-status.json`) |
| `scripts/geocode.py`, `data/coords.json` | מיקום האצטדיונים למפה (OpenStreetMap) |
| `vendor/` | ספריית המפה Leaflet ו-markercluster |
| `scripts/import_from_html.py` | ייבוא חד־פעמי מקובץ הלוח המקורי |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה כאפליקציה ועבודה בלי אינטרנט |
